# 🎬 Mini Netflix SQL Projesi

Bu proje, temel SQL komutlarını pratik yapmak için oluşturulmuş bir film ve dizi veritabanıdır. 

## 🛠️ Kullanılan Teknolojiler
- SQL (CREATE, INSERT, SELECT, WHERE)

## 📌 Proje İçeriği
1. **Tablo Oluşturma:** `icerikler` adında bir tablo tasarlandı.
2. **Veri Girişi:** Tabloya çeşitli film ve diziler eklendi.
3. **Veri Çekme:** Türlere ve yayın yıllarına göre filtreleme yapan SQL sorguları yazıldı.
